# QoE Analysis

## Project Overview
This project analyzes Quality of Experience (QoE) for mobile network users in Cameroon. We identified key stakeholders, gathered data through surveys and interviews, and analyzed user satisfaction with network providers.

## Research Methods
- **Stakeholder Identification**: Identified mobile network providers and users as stakeholders
- **Data Collection**: Used surveys and interviews to gather qualitative and quantitative data
- **Data Analysis**: Cleaned collected data and performed statistical analysis

## Key Findings
- Average satisfaction rating: 2.00 out of 5
- Most common network problem: Expensive service
- Most common response to network issues: Toggling Airplane mode
- 85% of users have switched providers at least once
- "Not seeing results" is the leading hesitation factor for using network-related apps

## User Reluctance Assessment
We analyzed factors that make users hesitant to use network quality monitoring applications:
- Privacy concerns
- Not seeing immediate results from using such apps
- Excessive notifications
- Data usage concerns

## Next Steps
- Develop solutions based on identified pain points
- Create user-friendly network monitoring tools that address privacy and data usage concerns
